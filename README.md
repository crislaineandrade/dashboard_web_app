# Vehicle Sales Dashboard

## Overview

The Vehicle Sales Dashboard is a web application built with Streamlit that allows users to explore and visualize a dataset of vehicle sales advertisements. The application provides interactive charts to help identify patterns and better understand the data.

## Features

-Interactive histogram showing the distribution of vehicle mileage (odometer).
-Interactive scatter plot for exploring vehicle mileage data.
-Fast and responsive web interface built with Streamlit.
-Interactive visualizations powered by Plotly Express.

## Technologies Used

Python
Pandas
Streamlit
Plotly Express

## Project Structure

```text
dashboard_web_app/
├── app.py               # Main Streamlit application
├── vehicles.csv         # Dataset
├── requirements.txt     # Project dependencies
├── README.md            # Documentation
└── notebooks/           # Notebooks used during development
```

## Installation

Clone the repository:
git clone <git@github.com:crislaineandrade/dashboard_web_app.git>
cd dashboard_web_app
Create and activate a virtual environment (recommended):
conda create -n vehicles_env python=3.11
conda activate vehicles_env
Install the dependencies:
pip install -r requirements.txt
Running the Application

Start the Streamlit server by running:

streamlit run app.py

The application will open automatically in your default web browser.

## Purpose

This project demonstrates how to build an interactive web dashboard for data visualization using Python. It combines data processing with Pandas, interactive charts with Plotly Express, and a simple web interface using Streamlit.

# Dashboard de Vendas de Veículos

## Visão Geral

O Dashboard de Vendas de Veículos é uma aplicação web desenvolvida com Streamlit que permite explorar e visualizar um conjunto de dados de anúncios de venda de veículos. A aplicação oferece gráficos interativos para facilitar a análise e compreensão dos dados.

## Funcionalidades

-Histograma interativo mostrando a distribuição da quilometragem dos veículos (odometer).
-Gráfico de dispersão interativo para explorar os dados de quilometragem.
-Interface web rápida e intuitiva desenvolvida com Streamlit.
-Visualizações interativas criadas com Plotly Express.
